# Mary’s Team

A simple, mobile-friendly family schedule for Mary and Stu. Family and friends can see upcoming needs, volunteer by name, add items to their calendar, and share their availability.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Before family-wide use

The current version saves entries in each browser. Connect shared storage before inviting the family so everyone sees the same appointments, availability, and filled slots.
